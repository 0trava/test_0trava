# test_0trava  

Pet-проєкт для практики створення статичних сайтів із використанням **HTML, CSS і JavaScript**.  
Розгорнутий на GitHub Pages: [0trava.kyiv.ua](http://0trava.kyiv.ua)  

## Структура
- `blog pages` — сторінки та контент блогу  
- `images` — зображення й іконки  
- `js` — скрипти для взаємодії  
- `styles` — стилі для оформлення  
- `index.html` — головна сторінка  
- `style.css` — основний файл стилів  
- `CNAME` — налаштування для GitHub Pages  

## Призначення
Проєкт створено як навчальний майданчик для відпрацювання навичок веброзробки та тестування нових ідей.
